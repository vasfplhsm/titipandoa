# Locally hosted fonts

Downloaded from the Google Fonts repository (`google/fonts`, `main`):

- `ofl/cormorantgaramond/CormorantGaramond[wght].ttf`
- `ofl/inter/Inter[opsz,wght].ttf`
- `ofl/amiri/Amiri-Regular.ttf`

All are SIL Open Font License 1.1 fonts. Their copyright notices and full licenses
are included alongside the WOFF2 files. Cormorant Garamond and Inter were subset
to Latin (U+0000–024F) and general punctuation (U+2000–206F), preserving layout
features. Amiri retains its full Arabic character coverage. All were encoded as
WOFF2 with fontTools/Brotli. The app makes no external font requests.
