# Original illustrations

`mosque-sunset.svg` and `rosette.svg` are original vector illustrations created for
Titipan Doa during this redesign. They contain no third-party photographs or
traced reference-image assets. These two illustrations are dedicated to the
public domain under CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/.

The supplied design reference informs the interface layout and color palette;
its bitmap is not redistributed as an application asset.
